# Evaluation (Phase 2–3)

Empty by design. This directory is where the project's actual differentiator
lands; nothing here is generated yet.

## What goes here

**`gold_set.jsonl`** — 100 hand-labelled questions, each:

```json
{
  "id": "q001",
  "question": "Can a patient on warfarin take fluconazole?",
  "ideal_answer": "...",
  "supporting_chunk_ids": [1234, 1240],
  "drugs": ["warfarin sodium", "fluconazole"],
  "category": "interaction",
  "answerable": true
}
```

Categories: `interaction`, `dosing`, `contraindication`, `population`,
`boxed_warning`, plus an **adversarial** slice where `answerable` is `false` —
plausible-sounding questions the corpus genuinely cannot answer. That slice is
what makes the refusal path measurable rather than decorative.

Hand-labelling is the point. The gold set is the most valuable artifact in this
project and the one thing that cannot be generated by the system it evaluates.

## Metrics

Retrieval and generation are reported separately — they fail for different
reasons and are fixed by different changes.

| Layer | Metric | Source |
|---|---|---|
| Retrieval | Recall@k, MRR, context precision, context recall | `supporting_chunk_ids` |
| Generation | Faithfulness, answer relevancy | RAGAS (0.4.3) |
| Grounding | Hallucinated-citation rate, uncited-answer rate | already computed per query in Phase 1 |
| Refusal | Correct-refusal rate, over-refusal rate | the adversarial slice |
| Ops | p50/p95 latency, cost per query | provider usage fields |

## Planned runs

1. **Retrieval ablation** — dense → hybrid (dense + `tsv` full-text) → hybrid + reranker. The `tsv` column and GIN index already exist in the schema.
2. **Chunking ablation** — the current fixed-size baseline vs. semantic vs. parent-document.
3. **Model comparison** — Claude Haiku 4.5 vs. the local model, on quality against cost and latency.

## Judge model

RAGAS metrics need an LLM judge, and the judge must be stronger than the system
under test or the numbers are meaningless. Use a frontier Claude model on
Bedrock for judging, not the Haiku model being evaluated — and never the local
model. Budget a few dollars per full run and keep the judge fixed across
ablations, since changing it invalidates comparison with earlier runs.
